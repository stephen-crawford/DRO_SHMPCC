\begin{abstract}
Scenario-based Safe Horizon MPC is attractive for chance-constrained motion planning because it preserves tractability while providing finite-sample guarantees for i.i.d.\ sampled constraints. However, switching obstacle behaviors create significant problems for these appraoches as under a fixed scenario budget, rare but safety-critical dyanmic modes may be underrepresented. This paper addresses this problem in context of Safe Horizon Model Predictive Contouring Control (SH-MPCC). We model obstacle behavior using discrete dynamic modes with nominal belief $\widehat p_t^v$ and introduce a Wasserstein distributionally robust optimization (WDRO) layer that computes a conservative mode distribution $q^\star$ inside a Wasserstein ball around $\widehat p_t^v$. The resulting distribution is used in two ways: 1) to reweight scenario sampling; 2) to select a small number of deterministic high-risk mode representatives for injection as additional tightening constraints. Across multiple path geometries and interaction settings, the proposed method reduces missed-mode rate and collision rate relative to baseline SH-MPCC, showing that improving which modes are represented can substantially improve closed-loop safety without replacing the underlying scenario-based controller.
\end{abstract}

\section{Introduction}
Scenario-based MPC provides finite-sample guarantees for chance-constrained planning when uncertainty samples are drawn i.i.d.\ from the true distribution \cite{Cal2006ScenarioApproach,Ca2018ScenarioTheory}. In multi-agent planning, however, nearby obstacles may switch between discrete maneuver modes, and rare but safety-critical behaviors can be under-represented at practical scenario budgets. This leads to optimistic collision-risk estimates even when the underlying scenario program is theoretically sound.

We study this issue in the context of Safe Horizon Model Predictive Contouring Control (SH-MPCC) used to control a self-driving car, where collision constraints are enforced over a truncated safe horizon \cite{degroot2023SBMotionBounded}. The central problem of this paper is therefore how to improve the way that obstacle behaviors are sampled or selected so that SH-MPCC does not miss rare but dangerous switching modes.

Our contribution is not a new vehicle model or a new SH-MPCC formulation. Rather, we add a mode-aware scenario-generation layer on top of SH-MPCC. Starting from a nominal mode belief $\widehat p_t^v$, we use Wasserstein distributionally robust optimization (WDRO) to compute a conservative distribution $q^\star$ that shifts probability mass toward high-risk modes while respecting transport geometry between modes. We then use $q^\star$ in two ways: 1) to reweight scenario sampling; 2) to select a small number of deterministic mode representatives for injection as additional tightening constraints.

The paper makes three main contributions. First, we formulate the mode-underrepresentation problem that arises in scenario-based SH-MPCC under switching obstacle dynamics. Second, we introduce a WDRO-based mode-reweighting rule that improves which behaviors are represented under fixed scenario budget. Third, we show empirically across multiple path geometries and challenging interaction settings that this mode-aware scenario generation reduces missed-mode rate and improves closed-loop safety relative to baseline SH-MPCC.

\section{Problem Formulation}\label{sec:problem}

We consider Safe Horizon Model Predictive Contouring Control (SH-MPCC) with planning horizon $N$ and safe horizon $N_s \le N$. At each time $t$, the controller solves a finite-scenario optimization problem using $S$ sampled obstacle trajectories. The ego state is denoted by $x_t$, and the control sequence is $U_t=(u_{t|t},\dots,u_{t+N-1|t})$.

Each obstacle $v \in \{1,\dots,V\}$ is assumed to belong to a class $\mathcal{C}(v)$ possessing a finite maneuver-mode set $\mathcal{M}_{\mathcal{C}}=\{1,\dots,M_{\mathcal{C}}\}$. A predictor provides a nominal belief $\widehat p_t^v \in \Delta_{M_{\mathcal{C}}}$ over these modes. Conditioned on a mode $m \in \mathcal{M}_{\mathcal{C}}$, the predictor generates a trajectory realization over the safe horizon. In baseline scenario-based SH-MPCC, scenarios are generated by sampling modes from $\widehat p_t^v$ and then sampling trajectories conditioned on those modes.

The difficulty is that, when $S$ is limited, directly sampling from $\widehat p_t^v$ can under-represent rare but safety-critical modes. As a result, the controller may solve the correct scenario program for the sampled trajectories while still failing to account for the obstacle behaviors that matter most for safety.

Thus we can formalize the problem at hand as follows.
Given a fixed scenario budget $S$ and nominal mode beliefs $\{\widehat p_t^v\}_{v=1}^V$, we want to create a mode-aware scenario-generation rule for SH-MPCC that:
\begin{enumerate}
    \item preserves the sampled-constraint structure of the baseline scenario program;
    \item increases representation of rare but dangerous switching modes;
    \item improves closed-loop safety without replacing the underlying SH-MPCC optimization problem.
\end{enumerate}

The method proposed in this paper addresses this problem by placing a Wasserstein-DRO layer on top of the nominal mode beliefs. The resulting conservative distribution $q^\star$ is then used either to reweight scenario sampling or to select a small number of deterministic mode representatives for injection as additional constraints.

\section{Related Work}\label{related}
Scenario-based optimization provides a tractable surrogate for chance-constrained control by enforcing constraints on finitely many sampled realizations of the uncertainty \cite{Cal2006ScenarioApproach,Ca2018ScenarioTheory}. In motion planning and MPC, this paradigm has been used to reduce conservatism relative to analytic convex approximations while preserving real-time feasibility \cite{de2021ScenarioBasedTraj,degroot2023SBMotionBounded}.

De Groot et al.\ \cite{de2021ScenarioBasedTraj} control collision risk via per-step chance constraints in a receding-horizon replanning framework. In follow-up work, the same authors \cite{degroot2023SBMotionBounded} bound the joint probability of collision over the trajectory, reducing conservatism while retaining scenario-based tractability. This Safe Horizon MPC (SH-MPC) framework forms the basis of our implementation. Other scenario-based MPC variants introduce candidate-path representations \cite{Shang2021SceMPC} or reinforcement-learning-based components \cite{Jekl2025SceVelPlanning}, which are complementary to our focus.

More broadly, chance-constrained MPC for multi-agent collision avoidance has been studied using particle approximations, surrogate constraints, and parametric distributional assumptions, often Gaussian \cite{Blackmore2010ProbParticle,Gopalakrishnan2016CCMulti,Lyons2012CCMPCMulti,Zhu2019CCColl,wang2020NonGauss}. These methods typically assume a fixed probabilistic uncertainty model rather than explicitly addressing unknown switching behavior. Approaches that do model context-dependent or switching behaviors often rely on intent inference or structured prediction modules \cite{Kooij2019Context-based}.

A related but distinct line of work studies Wasserstein distributionally robust MPC, where ambiguity sets are embedded directly into the control problem to robustify against uncertain disturbance distributions, uncertain dynamics, or risk constraints through worst-case expectation or CVaR formulations \cite{Esfahani2017DDRDRO,kuhn2019wdro,Hakobyan2020WDRO,Zhong2021DDRMPC,gao2022distributionallyrobuststochasticoptimization,gao2023drso}. Representative examples include data-driven DR-MPC for uncertain linear systems, Wasserstein tube MPC with exact uncertainty propagation, and iterative DR risk-constrained MPC for motion planning with uncertain obstacles \cite{Aolaritei2023WTMPC,Zolanvari2023WDRRC,Micheli2022DDRMPC}. In these approaches, Wasserstein ambiguity sets are used to define robustified state, input, or risk constraints inside the MPC problem.

Our setting is different. We do not replace the scenario MPC problem with a Wasserstein-robust reformulation. Instead, we use Wasserstein-DRO as a mode-reweighting and mode-selection layer on top of SH-MPCC. Given a nominal belief $\widehat p_t^v$ over maneuver modes, we compute a worst-case distribution $q^\star$ within a Wasserstein ball and use it either to (i) sample scenarios from a more conservative, geometry-aware mode distribution or (ii) select a small set of mode constraints to inject into the optimization problem. In this way, DRO is used to improve finite-sample representation of rare but safety-critical modes at fixed scenario budget, rather than to impose a fully distributionally robust MPC constraint set.

In particular, unlike iterative DR-MPC approaches that construct Wasserstein-robust safe sets or CVaR-based motion-planning constraints over continuous uncertainty distributions (such as \cite{Zolanvari2023WDRRC}), our method operates on a discrete maneuver-mode representation and targets improved coverage of switching behaviors in scenario-based planning.

\section{Methodology}\label{methods}

This section formalizes the main components realted to the contribution. Specifically, we detail the baseline SH-MPCC scenario program, the WDRO mode-reweighting layer, and the WDRO-based injection rule. Common implementation details of the controller such as the ego model and use of fourth-order Runge--Kutta are not specific to the contribution and are therefore summarized only briefly in the experimental setup.

\subsection{Baseline SH-MPCC formulation}

The ego vehicle is modeled by a discretized second-order unicycle model, written compactly as
\begin{equation}
x_{t+1}^{\mathrm{ego}} = f^{\mathrm{ego}}(x_t^{\mathrm{ego}},u_t).
\end{equation}
Given a reference path $\Gamma$, the MPCC objective penalizes contouring error ($e_c(k)$), lag error ($e_l(k)$), control effort (acceleration $a_{t+k|t}$, angular velocity $ \omega_{t+k|t}$), and velocity tracking error ($ v_{t+k|t} - v_{\mathrm{ref}}$) at each step $k$, over the planning horizon.

The MPCC stage cost at step $k$ is
\begin{align}
    \ell_{\mathrm{MPCC}}(k) = w_c\, e_c(k)^2 + w_l\, e_l(k)^2 + \notag \\
    w_a\, a_{t+k|t}^2 + w_\omega\, \omega_{t+k|t}^2 + w_v (v_{t+k|t} - v_{\mathrm{ref}})^2, \label{eq:mpcc_cost}
\end{align}
where $w_c, w_l, w_a, w_\omega, w_v > 0$ are user-specified weights and $v_{\mathrm{ref}}$ is a reference velocity.

The robot footprint is approximated by $D$ discs of radius $r_d$ centered at offsets $\{c_1,\dots,c_D\}$ along the robot's longitudinal axis. The center of disc $d$ at horizon step $k$ is
\begin{equation}\label{eq:disc_center}
p_d(k) = \begin{bmatrix} p_x(k) + c_d \cos\theta(k) \\ p_y(k) + c_d \sin\theta(k) \end{bmatrix},
\end{equation}
where we abbreviate $p_x(k) := p_{x,t+k|t}$, etc.

Obstacle agents are indexed by $v \in \{1,\dots,V\}$. For each obstacle $v$, a motion predictor provides a distribution over future positions. We assume each obstacle belongs to a class $\mathcal{C}(v)$ with a finite mode set $\mathcal{M}_{\mathcal{C}} = \{1,\dots,M_{\mathcal{C}}\}$, where mode $m$ specifies a stochastic motion model
\begin{equation}\label{eq:obs_dyn}
x_{t+1}^v = f_m(x_t^v).
\end{equation}
The mode evolution process is unknown and may be non-Markovian.

Collision avoidance between each robot disc $d$ and obstacle $v$ at horizon step $k$
is enforced using a linearized half-space constraint for each scenario $i$.
Let $x^{v,(i)}_{t+k|t}\in\mathbb{R}^2$ denote the sampled obstacle position at step $k$ in scenario $i$. Define the outward normal from disc $d$ to obstacle $v$:
\begin{equation}\label{eq:normal}
\hat{n}_{d,v,k}^{(i)} =
\frac{x^{v,(i)}_{t+k|t} - p_d(k)}
{\max\!\left(\|x^{v,(i)}_{t+k|t} - p_d(k)\|, \varepsilon_{\min}\right)},
\end{equation}
where $\varepsilon_{\min} > 0$ guards against division by zero. The half-space
constraint is
\begin{equation}\label{eq:halfspace}
\hat{n}_{d,v,k}^{(i)\top} p_d(k)
\le
\hat{n}_{d,v,k}^{(i)\top} x^{v,(i)}_{t+k|t}
- (r_d + r_{\mathrm{obs}}^v + r_{\mathrm{offset}}),
\end{equation}
where $r_{\mathrm{offset}}\ge 0$ is an additional safety margin.

We enforce collision avoidance constraints only over a safe horizon $N_s \le N$
\cite{degroot2023SBMotionBounded}. All collision constraints and mode-risk computations
are truncated to $N_s$, while the control horizon for optimization remains $N$.
This yields the baseline SH-MPCC scenario program
\begin{subequations}\label{eq:scenario_opt}
\begin{align}
\min_{U_t \in \mathbb{U}^N}\quad &
\sum_{k=0}^{N-1} \ell_{\mathrm{MPCC}}(k) \label{eq:obj}\\
\text{s.t.}\quad &
x_{t+k+1|t}^{\mathrm{ego}} = f^{\mathrm{ego}}(x_{t+k|t}^{\mathrm{ego}}, u_{t+k|t}),
\quad x_{t|t}^{\mathrm{ego}} = x_t^{\mathrm{ego}}, \label{eq:dyn_constr}\\
& \hat{n}_{d,v,k}^{(i)\top} p_d(k)
\le
\hat{n}_{d,v,k}^{(i)\top} x^{v,(i)}_{t+k|t}
- (r_d + r_{\mathrm{obs}}^v + r_{\mathrm{offset}}), \label{eq:coll_constr}\\
& \quad \forall\, d=1,\dots,D,\ v=1,\dots,V, \notag \\
& \quad \forall\, k=1,\dots,N_s,\ i=1,\dots,S_{\mathrm{tot}}.
\nonumber
\end{align}
\end{subequations}
The contribution of this paper is again to modify how the scenarios in \eqref{eq:scenario_opt} are generated, not to replace the SH-MPCC optimization problem itself.

\subsection{Wasserstein-DRO mode reweighting} \label{sec:wass_prelim}

We now describe the key mechanism used to address the problem of Section~\ref{sec:problem}. Starting from the nominal belief $\widehat p_t^v$, we want to create an alternative distribution over obstacle modes that places more mass on dangerous behaviors while respecting geometric similarity between modes.

Let $\widehat p_t^v\in\Delta_{M_{\mathcal{C}}}$ denote a nominal belief over the $M_{\mathcal{C}}$ modes for obstacle $v$ belonging to class $\mathcal{C}(v)$ at time $t$.
To reshape mode weights in a geometry-aware way, we compute a worst-case distribution $q\in\Delta_{M_{\mathcal{C}}}$ in a Wasserstein ball around $\widehat p_t^v$:
\begin{equation}\label{eq:w_dro_modes}
\max_{q\in\Delta_{M_{\mathcal{C}}}}\ \langle q,r\rangle
\quad\text{s.t.}\quad
W_D(q,\widehat p_t^v)\le \rho,
\end{equation}
where $r\in\mathbb{R}^M$ is a per-mode danger score computed from predicted safe-horizon clearance violations (higher indicates greater risk), $W_D$ is the discrete Wasserstein distance induced by ground cost $D$, and $\rho$ is the Wasserstein radius \cite{Esfahani2017DDRDRO,Zhong2021DDRMPC,kuhn2024WDRO}. We scale the Wasserstein ambiguity radius to reflect the reliability of the empirical mode belief.
Let $n_{\mathrm{obs}}$ denote the number of mode observations available in the history window for obstacle class $C_v$.
We set
\[
\rho \;=\; \rho_0\!\left(1+\frac{\alpha}{\sqrt{n_{\mathrm{obs}}}}\right),
\]
where $\rho_0$ is a base radius (default $\rho_0=0.1$) and $\alpha$ is a user-set scaling coefficient (default $\alpha=1.0$).
This choice inflates the Wasserstein ball when observations are scarce and contracts as data accumulates (because $1/\sqrt{n_{\mathrm{obs}}}$ decays), yielding $\rho\to\rho_0$ in the well-observed regime.

We form $r$ using a conservative Gaussian clearance surrogate \cite{blackmore2012CCOPPW}. For mode $m$ and safe-horizon step $k$, let the predicted obstacle position satisfy $x_{t+k|t}^{v,m}\sim\mathcal N(\mu_{m,k}^v,\Sigma_{m,k}^v)$ and let $c_d(k)$ denote the center of ego disc $d$ at step $k$.
We then define a normalized straight line from the center of the ego disc to the obstacle
\[
n_{m,k,d}:=(\mu_{m,k}^v-c_d(k))/\|\mu_{m,k}^v-c_d(k)\|
\]
and calculate the directional standard deviation for the obstacle
\[
\sigma_{m,k,d}:=\sqrt{n_{m,k,d}^\top \Sigma_{m,k}^v\, n_{m,k,d}}.
\]
Given a one-sided quantile $z_\alpha$, the per-step violation is
\[
r_{m,k,d} := \bigl[R + z_\alpha \sigma_{m,k,d} - \|\mu_{m,k}^v-c_d(k)\|\bigr]_+,
\]
where $R=r_d+r_{\mathrm{obs}}^v+r_{\mathrm{offset}}$ is the total safety radius. We then set
\[
r_m := \max_{k\le N_s}\max_{d\le D} r_{m,k,d}.
\]

Note that $\widehat p_t^v$ is feasible for the Wasserstein ambiguity set
$\{q \in \Delta_{M_{\mathcal{C}}} : W_D(q,\widehat p_t^v)\le \rho\}$ since
$W_D(\widehat p_t^v,\widehat p_t^v)=0\le \rho$.
Therefore, for the worst-case reweighting problem
$q^\star \in \arg\max_{W_D(q,\widehat p_t^v)\le \rho}\langle q, r\rangle$,
we have
$\langle q^\star, r\rangle \ge \langle \widehat p_t^v, r\rangle$.

Thus $q^\star$ can be interpreted as a conservative mode distribution inside the Wasserstein ambiguity set. In our framework, $q^\star$ is used as Wasserstein-geometry-aware distribution guiding the sampling of dynamic modes over discrete. It affects the sampling such that the scenario set becomes biased towards behaviors that are both risky and reachable under the prescribed transport cost. This preserves the i.i.d.\ sampled structure of the scenario program while empirically improving representation of rare but safety-critical modes under fixed scenario budget.

For computational consideratoins, we make use of the Kantorovich dual. Using the Kantorovich dual for the $W_1$-type objective, \eqref{eq:w_dro_modes} reduces to a 1D convex minimization in $\lambda\ge 0$:
\begin{equation}\label{eq:w_dro_dual}
\min_{\lambda\ge 0}\ \Bigl\{
\lambda\rho+\sum_{i=1}^{M_{\mathcal{C}}} \widehat p_{t,i}^v\ \max_{j\in\mathcal M_{\mathcal{C}}}\bigl(r_j-\lambda D_{ij}\bigr)
\Bigr\},
\end{equation}
which we solve via a 1D search \cite{gao2022distributionallyrobuststochasticoptimization}.
Here, $\lambda$ is the Lagrange multiplier (price per unit transport), $\rho$ and $\widehat p_{t, i}^v$ are defined as before, and $\max_j(r_j-\lambda D_{ij})$ selects the best destination mode $j$ for mass starting at mode $i$ under the transport geometry.

We recover a candidate worst-case distribution by mapping each nominal mass at mode $i$ to
$j^\star(i)\in\operatorname*{arg\,max}_{j\in\mathcal M_{\mathcal{C}}}(r_j-\lambda^\star D_{ij})$ and verify that the induced transport plan satisfies the radius constraint (up to numerical tolerance) before using the resulting weights for sampling.

\subsection{WDRO-based scenario injection}

In addition to sampling from $q^\star$, we consider a second use of the WDRO solution in the form of deterministic mode injection. After computing $q^\star$, we select a small number of modes with the largest WDRO mass and inject their deterministic representatives (for example, mode-conditioned mean trajectories) as additional collision-avoidance constraints. This gives the optimizer explicit coverage of a few high-risk behaviors even when the stochastic scenario budget is small.

Formally, let $q^\star \in \Delta_{M_{\mathcal{C}}}$ denote the solution of \eqref{eq:w_dro_modes}. For a given injection budget $K$, we select the index set
\[
\mathcal{I}_K \subset \mathcal{M_{\mathcal{C}}}, \qquad |\mathcal{I}_K|=K, \qquad 
\mathcal{I}_K \in \operatorname*{arg\,max}_{|\mathcal{I}|=K}\ \sum_{l\in\mathcal{I}} q^\star_l,
\]
that is, the $K$ largest components of $q^\star$, and inject the corresponding deterministic representatives as hard constraints.

Importantly, these injected constraints are not treated as additional i.i.d.\ scenario samples. They act as a deterministic tightening layer on top of the $S$ sampled constraints. Therefore, if $\mathcal F_S$ denotes the feasible set defined by the $S$ sampled scenario constraints and $\mathcal F_{S,\mathrm{inj}}$ denotes the feasible set after injection, then $\mathcal F_{S,\mathrm{inj}} \subseteq \mathcal F_S$.

In the experiments, we compare this WDRO-based injection rule against a simpler TopRisk-$K$ baseline that selects injected modes greedily by their risk scores only. We keep that comparison in the results section, since it is used as an empirical baseline rather than as part of the main method development.

\subsection{Scenario generation}\label{sec:scenario_gen}

A scenario consists of obstacle trajectories for all obstacles over the safe horizon.
For each obstacle $v$, let the base predictor define a distribution over the stacked
vector $\xi_t^v \in \mathbb{R}^{2N_s}$ (concatenated obstacle positions across the safe horizon).
For each rollout, we generate scenarios by first sampling a mode $m$ and then sampling
trajectory noise from the base predictor conditioned on that mode.

This yields three controller variants. In base SH-MPCC, modes are sampled from $\widehat p_t^v$. In WDRO-sampling, modes are sampled from $q^\star$. In WDRO-$K$ injection, the $S$ sampled scenarios are drawn from $\widehat p_t^v$ and $K$ additional deterministic mode representatives are injected as tightening constraints.

\section{Results}\label{results}

We evaluate whether the proposed WDRO layer improves representation of switching obstacle behaviors under a fixed scenario budget, and whether that improved representation translates into safer closed-loop behavior. The controller uses a second-order unicycle ego model with fourth-order Runge--Kutta discretization. We compare four methods: base SH-MPCC, WDRO-sampling, WDRO-$K$ injection, and a TopRisk-$K$ baseline that selects injected modes greedily by risk score only.

The experiments are organized in two groups. First, we vary the reference-path geometry while keeping an oncoming obstacle interaction. Second, we study more difficult interaction settings including crossing, diagonal, mixed-obstacle, and dense multi-obstacle scenarios. These experiments are designed to test the same hypothesis across increasing difficulty under varying conditions. when the scenario budget is fixed, improving which modes are represented should reduce missed modes and improve safety. We evaluate safety and finite-sample mode representation using three primary metrics: collision rate, missed-mode rate, and mean clearance.


%------------------------------------------------------------------------------
\subsection{Path geometry comparison}\label{sec:res_geometry}

To test whether the proposed mode-reweighting mechanism is tied to a single benchmark geometry or remains effective across different road shapes, we compare four path geometries: Straight, Gentle-S, S-curve, and Tight-S. In each case, the obstacle begins ahead of the ego and moves on an approximately oncoming trajectory.

Figure~\ref{fig:fig_path_geometry} compares base SH-MPCC, WDRO-sampling, and WDRO injection across these four reference-path geometries.

Across all path geometries, the base SH-MPCC method exhibits the highest collision rates and the highest missed-mode rates. In contrast, WDRO-sampling substantially reduces missed-mode rate in every geometry, indicating that the Wasserstein reweighting consistently improves finite-sample representation of switching behaviors. These coverage gains are accompanied by strong safety improvements: both WDRO-sampling and WDRO injection reduce collision rate markedly relative to the base planner, with especially pronounced gains on the more difficult S-shaped paths. The results suggest that the proposed mode-reweighting mechanism is not narrowly tuned to a single road layout, but instead remains effective across different road shapes.

\subsection{Challenging interaction settings}\label{sec:res_env_variants}

To probe more difficult multi-agent interactions, we additionally consider a family of challenging situations. We compare across four varirations: Crossing, Diagonal, Mixed (2 obstacles), Mixed (3 obstacles), and Dense (4 obstacles). These settings increase ambiguity in obstacle behavior and place greater pressure on finite-sample scenario selection.

Figure~\ref{fig:fig_challenging_envs} reports results for these five environment variants.

Again, the base planner performs worst across all variants, with substantially higher collision rates and lower mean clearance. All WDRO-based methods improve safety relative to the base planner. WDRO-sampling consistently lowers collision rate while maintaining or improving clearance, showing that better mode coverage translates into more conservative avoidance behavior. Injection also performs well, particularly when the environment contains multiple interacting obstacles and a small deterministic budget must cover several distinct risky behaviors. These results reinforce the main mechanism of the method: under limited scenario budgets, performance depends critically on which behaviors are represented, and Wasserstein-based mode reweighting improves that representation.

\subsection{Injection-mode selection comparison}\label{sec:res_injection_comparison}

We also compare the proposed WDRO-$K$ injection rule against the simpler TopRisk-$K$ baseline across environments, injection counts, switching probabilities, and noise thresholds. In these experiments, WDRO-$K$ and TopRisk-$K$ show statistically similar performance. This suggests that, once deterministic mode representatives are injected, the principal benefit comes from adding explicit coverage of risky behaviors rather than from the particular heuristic used to choose among plausible high-risk modes.

%------------------------------------------------------------------------------
\subsection{Interpretation of sampling and injection}\label{sec:res_interpretation}

Taken together, the results suggest that the principal benefit of WDRO lies in improving finite-sample representation of risky switching behaviors under a fixed scenario budget. WDRO-sampling directly addresses this issue by redistributing mass toward high-risk modes while respecting the transport geometry between modes, which leads to lower missed-mode rates and improved safety. WDRO-based injection provides an additional tightening mechanism by forcing the optimizer to explicitly account for a small set of deterministic high-risk mode representatives. This is particularly useful when several distinct risky behaviors must be captured with only a small injection budget. In contrast, the base planner suffers because rare but safety-critical behaviors are often absent from the sampled scenario set altogether.

\section{Conclusion}\label{conclusion}

This paper considered a specific failure mode of scenario-based SH-MPCC under switching obstacle dynamics. With limited scenario budget, rare but safety-critical dynamic modes may be under-represented. This can lead to poor practical safety performance even when the sampled optimization problem is solved correctly. We addressed that issue by introducing a Wasserstein-DRO layer over discrete dynamic modes.

The main role of the WDRO layer is not to replace SH-MPCC with a fully robust reformulation, but to improve which obstacle behaviors are represented by the limited sampling. We showed two ways to use the resulting worst-case distribution $q^\star$: WDRO-sampling and WDRO-based scenario injection. Across multiple path geometries and challenging interaction settings, these mechanisms reduced missed-mode rate and improved closed-loop safety relative to baseline SH-MPCC. Ultimately, this suggests that in switching-dynamics settings, safety depends not only on how many scenarios are used, but also on which behaviors those scenarios represent. Wasserstein-based mode reweighting provides a lightweight way to make the scenario set more informative under practical online sampling budgets. Future work will explore the use of continuous dynamic modes.
