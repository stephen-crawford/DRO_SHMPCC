# Paper Figures Pipeline

End-to-end pipeline for generating all paper figures: which experiments run, which CSVs they produce, and which Python scripts generate figures from them.

---

## 1. Pipeline Overview

```
┌──────────────────────────────────────────────────────────────┐
│  STEP 1: Run C++ experiments                                  │
│  build/paper_experiment_runner [A|B|C|...|AB]                │
│  → Writes CSV files to build/paper_figures/                   │
└──────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌──────────────────────────────────────────────────────────────┐
│  STEP 2: Generate figures                                     │
│  cd build && python3 ../scripts/generate_results_figures.py  │
│  → Writes PNGs to build/paper_figures/                        │
└──────────────────────────────────────────────────────────────┘
```

- **Experiments** are in `tests/paper_experiment_runner.cpp`. Each experiment (A, B, C, ...) runs many rollouts, aggregates statistics, and writes CSVs to `paper_figures/`.
- **Figures** are in `scripts/generate_results_figures.py`. Each figure function loads CSV(s), plots, and saves a PNG.
- **CDC figures** are generated separately by `scripts/generate_d_figures.py` from CSVs in `cdc_paper_figures/`.

Additional CSVs are produced by other test binaries:
- `test_dro_framework` -- DRO validation (H1-H6)
- `test_paper_strategies` -- Strategy comparison
- `test_cdc_experiments` -- CDC paper D1-D4 experiments
- `test_generalization` -- Generalization experiments

## 3. Where DRO Lives in the MPC

### 3.1 High-level control flow (one MPC step)

```
1. Mode observations updated (controller.update_mode_observation)
2. Reference trajectory warmstart
3. Scenario sampling:
   - If custom weights → sample_scenarios_with_weights(...)
   - If ensure_mode_coverage → sample_scenarios_with_mode_coverage(...)
   - Else → sample_scenarios(...)
4. Safe horizon (pre-DRO): N_safe = compute_safe_horizon(S_pre)
5. If enable_dro: DRO worst-case weights → inject scenario(s) per obstacle
6. Prune dominated scenarios
7. Safe horizon (final): effective_horizon = compute_safe_horizon(S_for_sh)
8. Truncate constraints to steps 0..effective_horizon-1
9. Build linearized constraints → SQP + ADMM QP solve → return first control
```

### 3.2 DRO (Distributionally Robust Optimization)

**Purpose**: Find worst-case mode weights within a Wasserstein ball around nominal mode distribution, then inject additional scenario(s) so the MPC hedges against distribution shift.

**Config** (in `include/config.hpp`):
- `enable_dro` -- turn DRO on/off
- `injection_mode` -- DRO, ADVERSARIAL, QSTAR_SAMPLE, TOP_RISK_INJECT, DIVERSE_RISK_INJECT, etc.
- `dro_rho_base`, `dro_adaptive_rho` -- Wasserstein ball radius

**Key code locations**:

| Location | What happens |
|----------|-------------|
| `src/mpc_controller.cpp` constructor | If `config_.enable_dro`, creates `WassersteinDRO dro_` |
| `src/mpc_controller.cpp` `solve()` | Per obstacle: compute nominal weights, solve Kantorovich dual, inject worst-case scenario |
| `include/wasserstein_dro.hpp` | `WassersteinDRO`, `DROConfig`, `DROResult` declarations |
| `src/wasserstein_dro.cpp` | `compute_worst_case_weights()`, scenario generation, risk computation |

### 3.3 Mode weights ("OT" variant)

The "OT" paper variant uses `WeightType::WASSERSTEIN` -- a 0.3x frequency + 0.7x recency blend (not a Sinkhorn OT solver). This is implemented in `src/mode_weights.cpp`.

### 3.4 Safe horizon and DRO interaction

DRO uses the safe horizon to limit the risk horizon when computing worst-case weights. Only i.i.d. sampled scenarios count toward S for safe-horizon bounds. DRO-injected scenarios are additional deterministic constraints that do NOT count in the Calafiore-Campi bound.

## 4. File Reference

### Experiments (C++)

| File | Role |
|------|------|
| `src/experiment_harness.cpp` | **Canonical rollout engine.** All rollout logic: obstacle simulation, mode tracking, collision detection, path completion. |
| `include/experiment_harness.hpp` | Public API: `ExperimentConfig`, `RolloutRecord`, `ObstacleSim`, statistical helpers. |
| `tests/paper_experiment_runner.cpp` | **Configuration layer.** Defines experiments A-AB, maps variant to config, calls `run_experiment_rollout()`. |
| `tests/test_dro_framework.cpp` | DRO/SH validation tests H1-H6. |
| `tests/test_cdc_experiments.cpp` | CDC paper experiments D1-D4. |
| `tests/test_paper_strategies.cpp` | 8-9 strategy comparison. |
| `tests/test_strategy_sweep.cpp` | 60-condition parameter sweep. |
| `tests/test_tuning_sweep.cpp` | DRO rho and SH min tuning. |
| `tests/test_generalization.cpp` | Generalization experiments (path geometry, multi-obstacle, switching dynamics, mode diversity). |
| `tests/test_trajectory_dro.cpp` | Trajectory-level DRO analysis. |
| `tests/test_dro_benefits.cpp` | DRO-specific benefit experiments. |
| `tests/test_path_obstacle_sweep.cpp` | Path geometry variation. |
| `tests/test_obstacle_class.cpp` | Obstacle class sharing validation. |
| `tests/test_paper_figures.cpp` | Legacy figure generation. |

### Core library (C++)

| File | Role |
|------|------|
| `include/config.hpp` | `ScenarioMPCConfig`: all hyperparameters, `compute_safe_horizon()` |
| `include/mpc_controller.hpp` | `AdaptiveScenarioMPC`: `solve()`, scenario management |
| `src/mpc_controller.cpp` | Full solve loop: sampling, DRO injection, SQP+ADMM |
| `include/wasserstein_dro.hpp` | `WassersteinDRO`: Kantorovich dual, injection strategies |
| `src/wasserstein_dro.cpp` | DRO implementation (1088 lines, largest module) |
| `include/mode_weights.hpp` | `compute_mode_weights()` for multiple strategies |
| `src/mode_weights.cpp` | FREQUENCY, WASSERSTEIN, UNIFORM, RECENCY, etc. |
| `include/scenario_sampler.hpp` | Scenario generation and mode-coverage sampling |
| `src/scenario_sampler.cpp` | Sampling implementation |

### Figure generation (Python)

| File | Role |
|------|------|
| `scripts/generate_results_figures.py` | Main paper figures (Fig 1-33) from `paper_figures/` CSVs |
| `scripts/generate_d_figures.py` | CDC paper figures D1-D4 from `cdc_paper_figures/` CSVs |
| `scripts/generate_generalization_figures.py` | Generalization experiment figures |

## 5. How to Run and Regenerate

### Full pipeline

```bash
# 1. Build
cmake -S . -B build
cmake --build build

# 2. Run all paper experiments (writes CSVs to build/paper_figures/)
cd build
./paper_experiment_runner

# 3. Run additional test suites for extra CSVs
./test_dro_framework
./test_cdc_experiments

# 4. Generate figures
python3 ../scripts/generate_results_figures.py
python3 ../scripts/generate_d_figures.py
```

### Single experiment

```bash
cd build
./paper_experiment_runner A
./paper_experiment_runner T
```

### Trace a specific figure

1. Find the figure in the table in section 2 (e.g. Fig 25 -> CSV `exp_t_missed_mode_vs_s.csv` -> experiment **T**)
2. Open `run_experiment_t()` in `paper_experiment_runner.cpp` to see variant configuration
3. Follow the control flow through `make_experiment_config()` -> `run_experiment_rollout()` in `experiment_harness.cpp`
4. Open `fig25_missed_mode_vs_s()` in `generate_results_figures.py` for plotting
