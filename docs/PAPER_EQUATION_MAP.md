## Mathematical changes authorized by this manuscript request

1. **Coordinate envelope:** replace maximization over the Wasserstein outer ball with `u_m = min(U_m, 1 - sum_{j != m} L_j)` on the CP-calibrated path. The certified set is C, not the ball. The same CP calculation now returns its envelope with its radius, preventing independent confidence allocations or mode-order mismatches. This affects probability floors, selected q, ζ, and automatic S. The transport LP and its tolerances are unchanged.
2. **Calibration observations:** on the held-mode CP-transfer controller path, retain each obstacle's own observations. Neither late-join initialization nor subsequent observation updates pool class siblings. The paper permits different stationary laws for different obstacles; pooling would require an additional common-law assumption. Legacy configurations retain class sharing.
3. **Zero-envelope convention:** when an envelope is explicitly supplied, coordinates with `u_m = 0` do not participate in the domination maximum, so `u_m = q_m = 0` is permitted. Positive u with zero q remains rejected as an unusable finite-factor allocation.

The previous five-argument `solve_dominating_ot` behavior remains available for fixed-radius/non-CP experiments and existing outer-ball regression tests. The paper's CP caller always supplies the polytope envelope. No existing test expectations were changed.

## Paper settings and boundaries

Use the default KT Dirichlet belief with `dro_enabled: true`, `use_domination_constraints: true`, `use_calibrated_radius: true`, the C++ default `wasserstein_radius_method = CLOPPER_PEARSON` (not a YAML option), `fixed_rho: -1`, `divergence: wasserstein`, `ground_cost: w2_bures`, `risk_measure: surrogate_var_bonferroni`, `risk_scoring_model: inherit` (or `certified_surrogate`), `risk_horizon: -1`, `markov_jump_system: false`, and no stratification. Automatic sizing implements the tightened certificate; manual sizing is allowed only if its acceptance inequality passes. Set `dangerous_risk_threshold` before sampling; 0.01 m is the existing configurable choice, not a number prescribed by the manuscript.

Alternative metrics, risk models, Markov sampling, fixed radius, non-CP calibration, external scenario overrides, and legacy allocation remain available as separate experiments; they are not the complete paper algorithm. Nominal-only class-sharing experiments also require one class per obstacle to represent distinct obstacle laws. Do not interpret every optional repository configuration as implementing this manuscript.

The numerical algorithms retain their existing floating-point tolerances. “Exact formulation” means the stated optimization problem and formulas, not exact-real arithmetic or a new formal proof. The risk score and transport geometry require the stated valid mode library and positive horizon. Statistical guarantees require error-free IID stationary calibration labels, correctly specified held-mode kernels, conditional obstacle independence, and the existing SH theorem's assumptions. The simulation world still uses its existing mode/noise behavior, which need not satisfy the assumed horizon kernel. Unspecified MPC objectives, constraints, recovery policy, support estimation, solver tolerances, and simulator logic were left unchanged.
